## 🚀 Flagship Systems & Projects

### 📡 [Wildfire Operations Center & LoRa Sensor Fleet](https://github.com/pratikk121/Forest_fire_supprestion)
> **End-to-End Field IoT Disaster Response System**  
> Connects solar-assisted ESP32 field sensor nodes over 433.0 MHz LoRa radio (SX1278) to a central base station gateway. A local Python serial bridge ingests packets, validates ranges, and streams records into PostgreSQL via Server-Sent Events (SSE) to render a live GIS situational map.  
> *Stack: ESP32 (C++ Firmware), LoRa SX1278, Python Serial Bridge, Next.js, PostgreSQL, Leaflet GIS.*

### 🖥️ [AetherOS Browser Compositor & Window Manager](https://github.com/pratikk121/Ather_os)
> **Experimental In-Browser Desktop Operating Environment**  
> Multi-surface window manager featuring custom WebGL glass shaders, GPU uniform buffer coordination, and an LRU-ordered focus stack that normalizes active window depths to eliminate z-index drift.  
> *Stack: TypeScript, WebGL2 / GLSL, React 19, IndexedDB, Tailwind CSS.*

### 🔬 [Parametric FEA Simulation Engine & 3D Viewer](https://github.com/pratikk121)
> **Scientific Modeling & Numerical Tensile Testing Framework**  
> Complete 3D FEA modeling architecture developed to replicate experimental direct-tension tests on reinforced composite specimens. Automates ANSYS MAPDL generation, features an independent Python numerical solver, and embeds an interactive 3D WebGL specimen inspector for real-time model verification.  
> *Stack: Python, NumPy, SciPy, ANSYS MAPDL, APDL Scripting, WebGL 3D.*

### 🏢 [Devlogic Systems Commercial Platform & Scoping Engine](https://github.com/pratikk121/Devlogic-New)
> **Production Studio Platform & Architectural Scoping Engine**  
> The official web presence for Devlogic Systems. Features an interactive project scoping tool that models feature prerequisites as a directed acyclic graph (DAG) to compute development timelines and budgets with zero client-side latency.  
> *Stack: React 19, Vite 6, Tailwind CSS v4, TypeScript.*

### 📦 [DeliveryDesk: Client Handover & Escrow Portal](https://github.com/pratikk121)
> **Automated B2B Software Delivery & Milestone Escrow Gateway**  
> Solves client payment delays by organizing standardized 12-section technical documentation packages and source code behind an automated payment webhook clearance gate (Razorpay/Stripe).  
> *Stack: Next.js 16, Supabase, Stripe / Razorpay Webhooks, Dynamic PDF Generation.*

### 💳 [FinanceTracker Backend Engine](https://github.com/pratikk121/fianace_tracker)
> **Decoupled Asynchronous Transactional Financial Engine**  
> Self-hosted financial management service featuring asynchronous FastAPI route handlers, PostgreSQL database with SQLAlchemy 2.0 ORM, and strict Pydantic v2 boundary sanitization.  
> *Stack: Python, FastAPI, PostgreSQL, SQLAlchemy 2.0, Pydantic v2.*
